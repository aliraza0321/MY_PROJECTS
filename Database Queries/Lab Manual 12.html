Lab 12: Library Management System

Introduction to Data Modeling Tutorial Using ERwin | Database Systems

Objective

The objective of this lab is to create a logical data model for a Library Management System using ERwin-style entities, primary keys, attributes, relationships, and a data dictionary report.

Case Study

The Library Management System monitors and controls library transactions. It maintains records of books, members, librarians, vendors, borrowing, returning, requests, searching, insertion, updating, and report generation.

End User Description
Librarian Maintains and updates records and handles the needs of library users.
Reader Searches books, borrows books, returns books, and places requests.
Vendor Provides books according to the requirements of the library.

ERwin Model Settings

Model Type: Logical/Physical
Notation: Information Engineering
Relationship Style: Mostly non-identifying relationships, with BOOK_AUTHOR as an identifying relationship.
